1 · Información general

Propósito y alcance

VetSphere es un sistema web académico para apoyar la operación de una clínica veterinaria. Integra una interfaz Angular, servicios REST en Spring Boot y una base de datos SQL Server. En el perfil local se usan datos ficticios para demostración.

Producto
VetSphere, gestión clínica veterinaria
Usuarios
Administración, veterinaria, recepción y clientes
Alcance revisado
Inicio de sesión, permisos, pacientes, agenda, farmacia, historias clínicas y reportes
Base de evaluación
ISO/IEC 25010:2023 e ISO/IEC 27001:2022 con Amd 1:2024

5 · ISO/IEC 27001:2022

Seguridad y tratamiento del riesgo

El software incorpora controles técnicos que apoyan la seguridad. La conformidad con ISO/IEC 27001 requiere además que la organización defina el alcance y los riesgos del SGSI, aplique controles, conserve evidencias y mantenga un proceso de mejora continua.

Controles visibles en el producto

  • Autenticación y autorización por roles en el backend.
  • Almacenamiento de contraseñas con BCrypt y secretos fuera del código.
  • Validación de datos recibidos y límites de tamaño para archivos.
  • Conexión local a SQL configurada para cifrado; certificado de producción pendiente.

Evidencias que faltan para una auditoría

  • Alcance aprobado, inventario de activos y evaluación de riesgos.
  • Declaración de aplicabilidad, responsables y políticas de seguridad.
  • Pruebas de autorización, recuperación, respaldo y restauración.
  • Gestión de incidentes, retención, continuidad y revisión periódica.

6 · Conclusión

Conclusión de la evaluación

La aplicación cuenta con una base funcional para demostrar una clínica veterinaria y controles técnicos iniciales. La evaluación no equivale a una certificación ni demuestra por sí sola conformidad con ISO/IEC 27001. Para cerrar el informe, registra el entorno, versión, fecha, casos ejecutados, resultado observado y evidencia de cada criterio.

Plantilla de evidencia: criterio · escenario probado · resultado esperado · resultado obtenido · captura o registro · observación y mejora propuesta.
