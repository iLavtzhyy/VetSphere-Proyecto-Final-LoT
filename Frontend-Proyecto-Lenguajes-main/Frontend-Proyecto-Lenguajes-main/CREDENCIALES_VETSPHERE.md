# Credenciales VetSphere

No se publican credenciales de acceso en el repositorio. Para pruebas locales aisladas, habilita el seeder local del backend con una contraseña nueva configurada mediante `DEMO_SEED_PASSWORD`; todas las cuentas de demostración reciben esa clave y deben eliminarse antes de cualquier despliegue.

## Nota de seguridad

- No compartas contraseñas por chat ni las guardes en documentación versionada.
- Usa secretos distintos para SQL Server, JWT, SMTP y SOAP.

## Inicio rapido

1. Backend: `http://localhost:8080`
2. Frontend: `http://localhost:4200`
3. Pantalla de login: `http://localhost:4200/login`
