Visión General

¿Qué es VetSphere?

🏥 Gestión Clínica Completa

Sistema integral para clínicas veterinarias que cubre: agenda de citas, historial clínico, cirugías, hospitalizaciones, laboratorio, facturación, farmacia e inventario.

🔗 Integración B2B vía SOAP

Comunicación segura con proveedores externos mediante servicios web SOAP con WS-Security (UsernameToken + PasswordDigest) para actualizaciones de inventario.

👥 Multi-Rol con JWT

4 roles diferenciados: Administrador, Veterinario, Recepcionista y Cliente. Cada uno con permisos específicos validados en backend con Spring Security.

📊 Reportes Automatizados

Generación de reportes en PDF (OpenPDF) y Excel (Apache POI) para historial clínico, finanzas y comprobantes de pago directos al navegador.

Integración B2B

Servicios SOAP con WS-Security

📡 Endpoint SOAP

Expuesto en /soap/productos

  • Consultar producto por código
  • Crear nuevos productos
  • Actualizar stock y precios
  • WSDL auto-generado por CXF

🔒 WS-Security (JAAS)

Seguridad a nivel de mensaje XML

  • Header <wsse:Security>
  • UsernameToken + PasswordDigest
  • WSS4J interceptor valida firma
  • CallbackHandler con JAAS
  • Nonce + Created anti-replay

🔄 Mini SOAP Client (:8090)

Aplicación independiente que simula un proveedor externo. Conecta su propia base VeterinariaMiniDB con el SOAP del backend principal para transferencias de stock bidireccionales. Protegida con un token API de 64 caracteres.

Resumen del Proyecto

🏗️ Arquitectura

Ecosistema de 3 servicios desacoplados con comunicación REST (frontend) y SOAP (B2B), siguiendo arquitectura por capas con organización modular.

🛡️ Seguridad

Doble capa de protección: JWT para REST y WS-Security con PasswordDigest para SOAP. Variables de entorno para credenciales. OTP por email.

📊 Calidad

Score global de 94/100 bajo ISO/IEC 25010. Complejidad media baja (2.1). 27 archivos de tests detectados. 0 hallazgos de seguridad estática.

VetSphere demuestra cómo una arquitectura híbrida moderna puede coexistir: REST proporciona agilidad para la UI, mientras SOAP con WS-Security garantiza transacciones seguras y auditables con proveedores externos.
